# TRMNL Running Board

One full screen with this week's training from [Tredict](https://www.tredict.com), a form graph
(Tredict's performance, computed from Tredict efforts), this week's heart-rate intensity as a bar under the graph and
the best run window today from the [run-window API](https://run.xadi.eu). English and Dutch.

It draws on the TRMNL OG (800x480) and the TRMNL X (1040x780), each in landscape or portrait. All text uses the
framework's text classes, so the sizes follow the device: the X steps up on the framework's `lg:` sizes, and day items
may take two lines there. In portrait the week sits on top. On the X the form and the run window sit side by side below
it. On an OG turned to portrait they are stacked, and the intensity bar is left out to make room.

## Install as a private plugin

1. In TRMNL, go to Plugins, then Private Plugin, and import a zip of `settings.yml`, `transform.js` and the five
   `.liquid` files from this folder. Leave the serverless language on the default.
2. Fill in the settings (below).
3. Add the plugin to a playlist. Set the device refresh to 30 minutes or less: the screen shows the last image until
   the next refresh.

`transform.js` is generated by `npm run build:trmnl` from `src/`; do not edit it by hand. `node tests/trmnl/preview.js
<dir> [--screen og|og-portrait|x|x-portrait]` writes an HTML preview of the render cases for that screen (it loads
TRMNL's stylesheet and script from trmnl.com).

## Settings

| Setting                | Default             | Notes                                                                          |
| ---------------------- | ------------------- | ------------------------------------------------------------------------------ |
| Tredict token          |                     | In Tredict: Settings, Personal API, scope `activityRead` only.                 |
| Location               |                     | Where you usually start your runs, for example Amsterdam centre (52.37, 4.89). |
| Hours you can run      | `07-09,12-14,17-21` | `HH-HH` ranges, comma separated. Minutes are allowed: `07:30-09:15`.           |
| Running in the dark    | Avoid darkness      | Whether a window may include time between sunset and sunrise.                  |
| Maximum chance of rain | 40%                 | 20, 40 or 60%.                                                                 |
| Calendar sports        | Running only        | The form graph always counts all sports.                                       |
| Language               | Device language     | Falls back to English when the device language is not supported.               |
| Theme                  | Light               | Dark shows the board in white on black. TRMNL's own dark mode also inverts it. |

The plugin polls `run.xadi.eu` every 30 minutes.

## The token

Tredict pauses a Personal API token unless the Tredict app is opened at least every 10 days. When it pauses, the
screen says "Tredict token paused. Open the Tredict web app to reactivate it." (Tredict answers HTTP 401); open the app
and the token works again. An invalid token (HTTP 403) gets its own message.

## Tredict calls

As Tredict asks, the script calls Tredict one request at a time, within 4 seconds in total. The intensity bar costs one
extra call per new run of the week. A run's detail is fetched once, when the call succeeds, and cached in the plugin's own
data; a failed call is tried again on a later poll, and the first failed detail call ends that poll's detail calls. As Tredict asks, it respects an HTTP
429: it makes no Tredict calls for the `Retry-After` time clamped to 30 minutes .. 6 hours, or 30 minutes when there is
none, and shows what it has.

## Privacy

The token is stored in TRMNL and sent only to Tredict, by the transform script after each poll. `run.xadi.eu` never
receives it, and the plugin sets no polling headers. It gets the location rounded to 2 decimals, your hours and the
two weather settings, and logs the location rounded to 1 decimal only. No other server sees Tredict data, and the
script keeps only what the screen needs, plus this week's activity ids with their low/moderate/high heart-rate
seconds (`intensityCache`) in TRMNL's merge variables.

## Publishing

This stays a private plugin. Tredict's terms restrict forwarding data to third parties in an automated manner, so
publishing it as a recipe waits for Tredict's written agreement.

# TRMNL Running Board

One full screen (800x480) with this week's training from [Tredict](https://www.tredict.com), a form graph
(estimated from Tredict efforts) and the best run window today from the
[run-window API](https://run.xadi.eu). English and Dutch.

## Install as a private plugin

1. In TRMNL, go to Plugins, then Private Plugin, and import a zip of `settings.yml`, `full.liquid` and `transform.js`
   from this folder. Leave the serverless language on the default.
2. Fill in the settings (below).
3. Add the plugin to a playlist. Set the device refresh to 30 minutes or less: the screen shows the last image until
   the next refresh.

`transform.js` is generated by `npm run build:trmnl` from `src/`; do not edit it by hand. `node tests/trmnl/preview.js
<dir>` writes an HTML preview of the render cases.

## Settings

| Setting                | Default             | Notes                                                                          |
| ---------------------- | ------------------- | ------------------------------------------------------------------------------ |
| Tredict token          |                     | In Tredict: Settings, Personal API, scope `activityRead` only.                 |
| Location               |                     | Where you usually start your runs, for example Amsterdam centre (52.37, 4.89). |
| Hours you can run      | `07-09,12-14,17-21` | `HH-HH` ranges, comma separated. Minutes are allowed: `07:30-09:15`.           |
| Running in the dark    | Avoid darkness      | Whether a window may include time between sunset and sunrise.                  |
| Maximum chance of rain | 40%                 | 20, 40 or 60%.                                                                 |
| Calendar sports        | Running only        | The form graph always counts all sports.                                       |
| Language               | Device language     | Falls back to English when the device language is not supported.               |

The plugin polls `run.xadi.eu` every 30 minutes.

## The token

Tredict pauses a Personal API token unless the Tredict app is opened at least every 10 days. When it pauses, the
screen says so; open the app and the token works again.

## Privacy

The token is stored in TRMNL and sent only to Tredict, by the transform script after each poll. `run.xadi.eu` never
receives it, and the plugin sets no polling headers. It gets the location rounded to 2 decimals, your hours and the
two weather settings, and logs the location rounded to 1 decimal only. No other server sees Tredict data, and the
script keeps only what the screen needs.

## Publishing

This stays a private plugin. Tredict's terms restrict forwarding data to third parties in an automated manner, so
publishing it as a recipe waits for Tredict's written agreement.
